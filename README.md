# AI Chatbot QA Lab

A hands-on portfolio project focused on testing AI chatbot quality, correctness, and reliability.

## Project Goals
- Evaluate whether chatbot answers are relevant and accurate.
- Identify incorrect, incomplete, or misleading responses.
- Test edge cases and ambiguous user questions.
- Document bugs with clear reproduction steps.

## Testing Areas
- Functional Testing
- Negative Testing
- Edge Case Testing
- Response Quality Evaluation
- Bug Reporting

## Project Status
🚧 In progress — building test cases and evaluation reports.
